NISCHINTO — PREMIUM MEDICAL & HEALTHCARE WEBSITE

IMPORTANT: This version is a standalone website. You do NOT need Node.js, React, npm, VS Code, or any installation.

HOW TO OPEN
1. Download the ZIP file.
2. In Windows, right-click the ZIP file and choose "Extract All...".
3. Open the extracted folder named Nischinto-Premium-Website.
4. Double-click index.html. It will open in Chrome, Edge, or another browser.

FILES
- index.html — complete website (HTML, CSS and JavaScript are included in one file)
- README.txt — these instructions

FEATURES
Responsive desktop/tablet/mobile layout, sticky navigation, mobile menu, interactive department tabs, appointment request demo, doctor profiles, gallery, testimonials, pricing, FAQ accordion, newsletter demo, blog and footer.

IMAGES AND FONTS
Images and Google Fonts load from the internet, so an internet connection is needed for the full visual design.

FOR PRODUCTION
The appointment and newsletter forms are front-end demos. Connect a backend or form service before using them to collect real submissions. Replace demo contact details and images with your own licensed assets.
